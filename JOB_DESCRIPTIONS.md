# Pravaron Careers - Job Description Details

## AI/ML & Backend Intern

Employment Type: Internship
Work Mode: Onsite
Experience Required: 0-1 year
Eligibility: Recent graduates (2025, 2026)
Number of Openings: 1
Location: Sector 140A, Noida

### Role Overview

Pravaron Technologies is looking for an AI/ML & Backend Intern to contribute to generative AI, machine learning, agentic systems, backend APIs, automation workflows, and intelligent product development.

The intern will work with the engineering team on AI experiments, RAG systems, data processing, API integrations, Flask-based backend services, PostgreSQL databases, and small production features.

### Responsibilities

- Assist in developing AI and machine-learning prototypes.
- Help build AI agents and intelligent automation workflows.
- Assist with RAG pipelines using documents and structured data.
- Research language models, AI frameworks, APIs, and open-source tools.
- Build and test prompts and structured AI outputs.
- Work with embeddings, vector databases, and semantic search.
- Prepare, clean, label, and validate datasets.
- Evaluate AI responses for accuracy, relevance, and hallucinations.
- Create evaluation datasets and test cases.
- Develop Python scripts, utilities, and backend modules.
- Build and maintain basic Flask REST APIs.
- Assist with PostgreSQL database models, queries, and integrations.
- Integrate AI services with backend applications and external APIs.
- Support document-processing and information-extraction systems.
- Assist with authentication, validation, and error handling.
- Write unit tests and participate in debugging.
- Document experiments, APIs, observations, and results.

### Required Skills

Python fundamentals; basic ML concepts; generative AI and LLM basics; Flask or backend knowledge; REST APIs; PostgreSQL or SQL; Pandas; NumPy; Git and GitHub; data processing; debugging; clear communication.

### Preferred Skills

AI/ML projects; Flask or FastAPI; SQLAlchemy; PostgreSQL or MongoDB; LangChain, LangGraph, LlamaIndex; Hugging Face; scikit-learn; PyTorch or TensorFlow; vector databases; NLP; Selenium or Playwright; Docker; Linux; cloud deployment; hackathons.

### Education

B.Tech/B.E. in Computer Science, Information Technology, or Artificial Intelligence and Machine Learning. Recent graduates from 2025 or 2026 are prioritized for internship roles.
